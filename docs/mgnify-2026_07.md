# MGnify Proteins 2026_07: what the release provides

Notes from the release README/STATS and remote Parquet metadata (checked 2026-09-28).
Source: https://ftp.ebi.ac.uk/pub/databases/metagenomics/peptide_database/current_release/
(CC0). Fetch a local sample with `uv run python scripts/fetch_mgnify_sample.py`.

## Files that matter for the index

| File | Size | Use |
| --- | --- | --- |
| `mgy_protein_sequences.parquet` (`protein_id`, `full_length`, `sequence`) | 1.0 TB | Member sequences |
| `mgy_cluster_seqs.parquet` (`cluster_rep`, `cluster_member`) | 39 GB | 90% membership |
| `mgy_clusters.parquet` (size, assembly count, biomes) | 11 GB | Unit metadata, biome filter |
| `mgy_proteins_pfam.parquet` (protein, Pfam, scores, coordinates) | 110 GB | Functional labels, for all proteins, not just reps |
| `mgy_biomes.parquet` (protein, biome, count) | 24 GB | Biome subsets |
| `mgy_clusters.fa.gz` (reps, header `FL=0/1`) | 157 GB | Representatives only |
| `mgy30/mgy30_c2.fasta.gz`, `_c5_fl`, `_c5_ppfam` | 13 / 4 / 2.3 GB | 30% representatives, three subsets |

Parquet files are sorted by protein or representative id in row groups of ~123k rows
(a few MB; up to 55 MB for sequences), so an id range is cheap to read remotely with
DuckDB, but gathering the members of chosen clusters touches rows spread across the
whole id space (members of cluster 277 include ids 954756431 and 1079143076).

## Gaps against the plan

- **No 30% membership table.** MGnify30 is published only as representative FASTAs for
  three subsets (C2: clusters with ≥ 2 members, 128.7 M reps; C5-FL; C5-PPfam), with bare
  `>MGYP…` headers. The plan therefore uses MGnify90 clusters only; mapping them onto the
  C2 representatives is future work.
- The `mgy30` FASTA headers use a shorter id format (`MGYP11138715`) than the main files
  (`MGYP000001738121`); check they refer to the same integer `protein_id`.
- Singletons are 73% of clusters; the plan already applies no floor to singleton partials.
- A biome subset (e.g. human gut) of members needs a full scan of `mgy_cluster_seqs` and
  `mgy_protein_sequences`: an HPC job, not a laptop download.
